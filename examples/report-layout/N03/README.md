# Fictional example: choose a report layout

This example uses fictional messages, candidate artifacts, and results. The six labels demonstrate one roster. Each participant has a separate branch.

1. [BRIEF.md](BRIEF.md) keeps the source checkpoint and the common criteria together. [node.json](node.json) names the six selected participants.
2. During independent work, each records a submission and transcript in its own folder. The team's progress comes from the selected participants' status files.
3. After all delivered, the fictional user [opened review](REVIEW-OPEN.md). Each participant compared the other candidates against the common criteria.
4. The fictional user [chose a result](decision.json). One assistant verified the resulting [layout](layout.md) and recorded the [merge](FINAL.md).
